## 环境准备（各期共用）

- [ ] CMake + MinGW：`cmake -S . -B build -G "MinGW Makefiles"` && `cmake --build build`
- [ ] **管理员**终端运行 `dnsrelay`（绑定 UDP 53）
- [ ] 记录原 DNS：`ipconfig /all`
- [ ] 本机 DNS 设为 `127.0.0.1`（二期全面测试；一期可用 `nslookup` 指定或未改系统 DNS 视实现而定）
- [ ] 上游地址：命令行传入或默认 `202.106.0.20`
- [ ] Wireshark：`udp.port == 53`

## 一期测试（透明中继）

**操作指南**：[testing-release1.md](./testing-release1.md)（含编译、单元测试、管理员中继、对比上游）。

| ID | 场景 | 操作步骤 | 预期结果 | 状态 |
|----|------|----------|----------|------|
| P1-T01 | 构建运行 | `dnsrelay -d <上游>` | 进程监听 53，无崩溃 | 已测 |
| P1-T02 | 公网解析 | `nslookup www.baidu.com 127.0.0.1` | 与直连上游一致 | 已测 |
| P1-T03 | ID 映射 | Wireshark 看中继→上游 与→客户端 的 ID | 上游 ID≠客户端 ID；回包 ID 恢复 | 未测 |
| P1-T04 | 大包丢弃 | 若可构造 >512 入站 | 程序不崩溃、不转发 | 未测 |
| P1-T05 | 上游超时 | 错误上游 IP + `-d` | 无回包、不僵死、日志有超时 | 未测 |
| P1-T06 | 双查询并发 | 快速连续两次 `nslookup` 不同名 | 两次均正确、无串答 | 未测 |

**一期不要求**：`dnsrelay.txt`、拦截、本地合成。

**已验证上游示例**：`220.181.111.1`、`220.181.111.232`（2026-05 联调）。
