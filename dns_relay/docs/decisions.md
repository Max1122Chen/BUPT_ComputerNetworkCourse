# 架构决策记录（ADR）

记录 **已确认** 的技术选择。实现与 AI 协作以本文及 [design.md](./design.md) 为准。

## ADR-000：目标平台与构建方式

- **状态**：已接受
- **日期**：2026-05-18
- **决策**：Windows **x64**；**CMake + MinGW-w64 GCC**；不使用 Visual Studio 工程。
- **后果**：链接 `ws2_32`；`WSAStartup` 集中于 platform 模块；绑定 53 需管理员权限。

- **状态**：已接受
- **日期**：2026-05-18
- **决策**：**C11**；仅标准库 + OS API；**禁止第三方库**；哈希表、LRU、链表等自实现。
- **后果**：见 [coding-style.md](./coding-style.md)。

## ADR-002：项目分期策略

- **状态**：已接受
- **日期**：2026-05-18
- **背景**：需先调试通路，再实现课设语义，最后可选优化。
- **决策**：
  - **一期**：透明中继（方案 B：`id_map` + 仅改 ID），不读配置、不本地应答。
  - **二期**：静态表三种 Case + 完整并发/超时/命令行（课设验收主体）。
  - **三期**：内存 **LRU cache**，接入「表 → cache → 中继」查找链。
- **理由**：降低排错难度；二期复用一期中继与 `id_map`，衔接成本低。
- **后果**：进展报告可展示一期 Wireshark；正式验收以二期完成为准。

## ADR-003：Socket 数量

- **状态**：已接受
- **日期**：2026-05-18
- **决策**：**单 UDP socket** 绑定 `0.0.0.0:53`，客户端与上游通信均通过该 socket（`sendto`/`recvfrom`）。
- **理由**：DNS over UDP 无连接；并发由 `id_map` 区分，无需每客户端独立 socket。

## ADR-004：非 A/IN 查询与中继范围

- **状态**：已接受
- **日期**：2026-05-18
- **决策**：
  - **QTYPE=A 且 QCLASS=IN**：查静态表（二期）；命中本地处理，未命中中继。
  - **其他**：**不查表**，请求与响应（≤512）均 **原样中继**（仅改 ID）。
- **理由**：课设重点 A 记录；全转发保证浏览器/系统兼容。

---

## ADR-005：上游超时语义

- **状态**：已接受
- **日期**：2026-05-18
- **决策**：pending 超时后 **不向客户端发送任何报文**；删除 `id_map` 条目。
- **理由**：保持对客户端透明，不伪造 SERVFAIL；避免改变解析器重试行为。

---

## ADR-006：本地合成响应的 AA 位

- **状态**：已接受
- **日期**：2026-05-18
- **决策**：本地生成的响应（A 记录、NXDOMAIN）**AA=0**；从中继转发的报文 **保持上游原样**（含 AA）。
- **理由**：本机非互联网权威服务器；与需求讨论一致。

---

## ADR-007：UDP 512 字节限制

- **状态**：已接受
- **日期**：2026-05-18
- **决策**：
  - 入站报文 `>512`：**丢弃**。
  - 本地合成响应：长度 **≤512**。
  - 上游响应 `>512`：**丢弃**，不转发（一期、二期、三期均如此，直至实现 EDNS）。
- **理由**：传统 DNS UDP 限制；未实现 EDNS 时的务实边界。

---

## ADR-008：一期并发（方案 B）

- **状态**：已接受
- **日期**：2026-05-18
- **决策**：一期即实现 **`id_map` + 改写 DNS ID**，不支持「完全不改 ID 的并行中继」。
- **理由**：多客户端下否则无法区分应答归属；与二期无缝衔接。
- **后果**：一期报文体仍原样，仅头 ID 变化；答辩时说明「逻辑透明、ID 映射」。

---

## ADR-009：配置文件格式

- **状态**：已接受
- **日期**：2026-05-18
- **决策**：每行 `IP 域名`（空白分隔）；域名入库前 **转小写**；重复域名 **后行覆盖前行**；参考 `docs/guidance/dnsrelay-example.txt`。
- **后果**：需处理样例中的长短域名、无 TLD 名称、大量 `0.0.0.0` 拦截项。
